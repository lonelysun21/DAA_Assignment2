## Project Description

This project implements three data structures from scratch:

- DynamicArray
- MyLinkedList
- MinHeap

The project also includes:

- operation counters for steps, moves, and comparisons;
- JUnit 5 tests;
- four benchmark workloads;
- CSV result export;
- benchmark plots;
- complexity analysis;
- loop invariant proofs.
